# Login com JavaScript puro

Código: [`packages/auth/examples/vanillaLogin.html`](../../packages/auth/examples/vanillaLogin.html).

Exemplo mínimo para aplicações sem framework. Substitua a publishable key, sirva o HTML por HTTP local e trate separadamente sucesso, 2FA e `AuthyonError`. Não abra o arquivo diretamente via `file://` em produção.
